# Prompt: 위키는 헤르메스를 거치고, 이동은 같은 바이트다

배경:

- `docs/code-review/completed/위키-inbox분류-원본유지-원인.md` (IRIS-REV-2026-1002-01)
- `docs/code-review/completed/위키기능-키워드휴리스틱-현황.md` (IRIS-REV-2026-1003-02)
- `docs/code-review/completed/위키폴더이동-노트미지정-원인.md` (IRIS-REV-2026-1003-01)

채팅 문장에 「위키」와 「삭제」가 있으면 `parse_wiki_command`가 노트 하나 삭제로 턴을 닫는다. 폴더를 만들고 챕터를 옮기라는 뒷문장은 헤르메스에 닿지 않는다. 헤르메스까지 가도 `wiki.write_user_note`는 새 요약 파일을 만들 뿐 inbox 원본을 옮기지 않는다. 완료 문장은 그 쓰기를 이동으로 통과시킨다.

이 프롬프트는 그 세 빈 자리를 구현 계약으로 고정한다. 위키 채팅은 키워드로 턴을 끝내지 않는다. 이미 있는 노트를 폴더로 보내는 일은 모델이 본문을 다시 쓰지 않는 도구다.

---

```text
Context:
- 저장소: Project-IRIS-Light (Windows / PyQt6)
- 입구: _execute_user_turn 이 Hermes 소유 여부를 보기 전에 try_wiki_command 를 호출하고, 명령이 있으면 return 한다.
- Hermes가 꺼져 있을 때만 _try_local_wiki_save 가 또 단어로 저장을 가로챈다.
- 카탈로그에 wiki.read_note, wiki.delete_note 는 이미 있다. 폴더 이동은 없다.
- wiki.list_notes 는 노트 배열 전체를 돌려주고 total 과 truncated 가 없다.
- settle_wiki_claim 은 「저장했」만 이번 턴 쓰기와 맞춘다. 「옮겼다」「분류했다」는 디스크를 보지 않는다.
- decide_followthrough 는 위키 목표이고 tool_ok_count==0 일 때만 이어 한다. write 가 ok 이면 분류 목표는 멈춘다.
- 기획상 Hermes는 필수다. 위키 기능은 Hermes가 켜졌는지와 무관하게 모델 도구 루프로 간다.

Goal:
1. 위키 채팅(저장, 목록, 열기, 삭제, 재가공, 폴더 이동·분류)은 키워드 파서가 턴을 닫지 않는다. Hermes 도구가 실행한다.
2. wiki.move_notes 는 이미 있는 user 노트의 바이트를 dest_folder 로 복사한 뒤 원본을 지운다. 모델이 content 를 넣지 않는다.
3. 폴더 소스는 그 폴더 이름을 dest_folder 아래에 유지한다. 파일 소스는 파일 이름만 붙인다. 사용자가 말한 폴더 문자열(강화학습, fine-tuning)은 슬러그로 바꾸지 않는다.
4. 「옮겼다」「분류했다」「이동 완료」인데 이번 턴 이동이 없으면, 쓰기가 있었을 때는 「새 요약 파일을 만들었고 inbox 원본은 그대로다」, 쓰기도 없으면 「노트는 그대로다」.
5. 학습자료+폴더+분류/저장, 또는 옮김/분류 목표는 write ok 만으로 끝나지 않는다. 이동이 없거나 목록이 잘렸으면 감독이 이어 한다.
6. wiki.list_notes 는 한 페이지와 함께 total, truncated 를 돌려준다.

Constraints:
- 새 에이전트 런타임, 스킬에 금지 문장만 더하는 것으로 끝내지 말 것. 도구와 완료 검사가 본 작업이다.
- parse_wiki_command 의 기존 op 분류는 지우지 말 것. 채팅 턴에서 그것을 실행하지 않을 뿐이다.
- docs 볼트는 옮기거나 지우지 말 것. `..` 경로는 거부.
- 목적지에 다른 바이트가 있으면 원본을 지우지 말 것.
- Qt 슬롯 밖으로 예외를 보내지 말 것. 새 MainWindow 속성은 __init__ 에서 만든다.
- 노트 원문 전체를 진행 로그에 남기지 말 것.

Interface:

1) 경유 (iris/ui/wiki_turn.py)
   wiki_requests_go_to_hermes() -> bool
   - 항상 True.
   - _execute_user_turn 은 이 값이 참이면 try_wiki_command 와 _try_local_wiki_save 를 호출하지 않는다.
   - 이어 하기가 위키 문장을 로컬 명령으로 다시 실행하지 않는다. 모델에게 도구를 호출하라는 기존 문장만 보낸다.

2) 이동 (iris/knowledge/wiki_move.py)
   move_user_bytes(wiki, sources, dest_folder) -> dict
   - sources: user/ 를 허용하는 파일 또는 폴더 rel.
   - dest_folder: 폴더. 파일명이면 거부. 한글·영문·하이픈은 그대로.
   - 폴더 소스의 각 md 는 dest_folder/<소스폴더이름>/상대경로.
   - 파일 소스는 dest_folder/<파일명>.
   - read_bytes / write_bytes. 검증 후에만 unlink. 빈 부모 디렉터리는 지운다.
   - 반환: moved[{from,to,bytes}], count, dest_folder, left, folders.
   - left 가 비고 count>0 이면 완료.

3) 도구 (iris/ui/control_actions/wiki.py, action_catalog.json)
   wiki.move_notes
   - args: sources 또는 rel_path 또는 from_folder, dest_folder.
   - content 는 받지 않는다.
   - 완료일 때만 진행 로그 ok. 트리를 갱신한다.
   - 색인 sync 는 성공한 이동 뒤에 시도한다. 실패해도 디스크 이동은 유지하고 결과에 index_error 를 남긴다.
   wiki.list_notes
   - page_note_rows: count(이번 페이지), total, truncated. 페이지 상한 40.
   wiki.write_user_note 요약에 기존 노트 이동은 move_notes 라고 적는다.

4) 완료 문장 (iris/knowledge/wiki_claim.py)
   relocate_goal(goal) -> bool
   - 옮/이동/분류 이고 (학습자료|폴더|위키|노트|inbox) 이거나
   - 학습자료 + 폴더 + 저장.
   wiki_work_goal 은 relocate_goal 이면 참.
   settle_wiki_claim(..., moved: bool = False)
   - relocate 목표이고 답에 옮겼|이동 완료|분류했|분류해 저장|inbox에서 가 있는데 moved 가 아니면
     wrote 이면 「새 요약 파일을 만들었고 inbox 원본은 그대로다」, 아니면 「노트는 그대로다」.

5) 감독 (iris/runtime/turn_followthrough.py)
   decide_followthrough(..., *, moved: bool = False, list_truncated: bool = False)
   - relocate 목적이고 완료처럼 말했는데 moved 가 아니면 continue.
   - relocate 목적이고 목록이 잘렸고 폴더 이동(moved_folder)이 아니면, 완료처럼 말했을 때 continue.
   - moved_folder 는 이번 턴에 폴더 소스를 남김 없이 옮겼을 때 True.
   - 상한 CAP 은 그대로.

6) 모델이 도구를 고르게 (integrations/hermes-skills/iris-control/iris-wiki/SKILL.md, hermes_memory_nudge)
   - 기존 노트를 폴더로 보내면 wiki.move_notes. write_user_note 로 본문을 다시 쓰지 않는다.
   - list 의 total 이 전체다. truncated 이면 그 페이지만으로 완료가 아니다.
   - 메모리 넛지는 이 문장이 없으면 갱신된다.

7) 확인
   python -m iris.knowledge.wiki_move
   python -m iris.knowledge.wiki_claim
   python -m iris.runtime.turn_followthrough
   python -m iris.ui.wiki_turn
   python -m iris.ui._check_control_action_split
   재현 문자열 「위키에서 내용들을 삭제해주고 폴더를 만들어 옮겨줘」는 parse 하면 delete 이지만,
   wiki_requests_go_to_hermes() 가 참이면 그 턴을 실행하지 않는다.
```
