| 항목 | 내용 |
|------|------|
| 작성일 | 2026-10-01 |
| 테스트 기간 | 2026-10-01 (목) ~ **2026-10-04 (일)** |

## 테스트 목적

이번 주 일요일(2026-10-04)까지, 현재 IRIS에 들어가 있는 기능을 QA가 같은 순서로 재현할 수 있게 한다. 정상 입력과 실패 입력을 같이 본다. 채팅 가독성, 채팅 확장 시 구체 페이드, Drag and Drop 첨부 표시는 이번 수정분이다.

통과는 화면과 실제 데이터(파일 내용, 폴더 컨텍스트, 도구 목록)가 맞을 때만 한다. 아이콘만 바뀌고 경로가 전달되지 않으면 실패다.

## 테스트 기간

이번 주 일요일까지. 마감일은 **2026년 10월 4일 (일요일)**.

## 테스트 환경

| 항목 | 기준 |
|------|------|
| OS | Windows 10/11 64bit |
| 실행 | `dist\IRIS.exe` (최신 소스 런처) 또는 `.venv\Scripts\python.exe -m iris` |
| 화면 | 메인 채팅과 IDE Companion 채팅을 각각 |
| 네트워크 | MCP, Skill GitHub, Hermes 클라우드 케이스는 연결 상태에서 1회, 끊은 상태에서 1회 |
| 샘플 | 텍스트 있는 PDF, 텍스트 없는 PDF, txt, png, 일반 문서, 폴더, 없는 경로 |
| 기록 | ID, 결과, 스크린샷 또는 로그 한 줄 |

IDE 채팅과 메인 채팅이 갈리는 항목(DND, BOOT, IDE)은 양쪽을 따로 적는다.
