01해결하려는 문제

AI 에이전트를 써 보고 싶어도
돈이 들거나 설치가 어렵습니다

에이전트 도구는 대부분 월 구독입니다. 무료로 쓰려면 모델 런타임과 에이전트를 직접 설치하고 서로 연결해야 하는데, 코딩을 막 배우기 시작한 사람에게는 쉽지 않습니다.

!비용매달 결제해야 합니다. 공부하거나 사이드 프로젝트를 하는 동안 구독료를 계속 내기는 부담스럽습니다.
!설치설치할 것이 많습니다. Ollama, 에이전트 게이트웨이, 모델을 따로 설치하고 포트도 맞춰야 합니다. 터미널이 익숙하지 않으면 여기서 멈추게 됩니다.
!연결모델만 설치하면 채팅까지만 됩니다. 파일을 고치거나 명령을 실행하게 하려면 에이전트 설정이 또 필요합니다.

대상  학생 · 취업 준비생 · 코딩 입문자

02IRIS가 하는 일

설치와 연결은
IRIS가 합니다

IRIS는 Windows용 데스크톱 앱입니다. 모델을 돌리는 Ollama와 도구를 실행하는 Hermes Agent를 설치해서 연결하고, 채팅창 하나에서 쓸 수 있게 해 줍니다.

01

설치

setup.bat이 파이썬 가상환경과 패키지를 준비하고, 앱을 처음 켜면 시작 프로토콜이 Ollama·모델·Hermes 설치를 이어서 진행합니다.

02

채팅이나 음성으로 작업

할 일을 적거나 말하면 Hermes가 파일을 고치고 터미널 명령을 실행합니다. 어떤 도구를 썼는지는 Live Activity 로그에 남습니다.

03

창 감시

지정해 둔 창이 승인을 기다리거나 에러로 멈추면 IRIS가 알림을 띄웁니다.

Live Activity / Internal Log

03AI 활용 방식

추론

Ollama 모델

Hermes Agent

파일 읽기·수정, 터미널 명령, 웹 검색을 실제로 실행합니다. 모델의 추론 과정과 도구 로그는 HUD에 바로 표시됩니다.

C
감시

멀티모달 모델

고정한 창을 최대 3개까지 캡처해서 승인 대기, 에러, 작업 멈춤 등 9가지 상태 중 하나로 판정합니다. 스크린샷 원본은 저장하지 않습니다.

D
앱 조작

MCP

IRIS가 켜질 때 Hermes에 iris-control MCP 서버를 등록합니다. 그래서 에이전트가 IRIS의 캘린더, 위키, 메일, 에뮬레이터를 직접 다룰 수 있습니다.

08확장성

기능은 스킬과
MCP 서버로 추가합니다

에이전트가 할 수 있는 일은 Hermes 스킬이나 MCP 서버를 추가해서 늘립니다. 대부분은 IRIS 코드를 고치지 않아도 됩니다.

Skills

IRIS가 켜질 때 스킬 10개를 Hermes에 동기화합니다. 스킬 폴더를 하나 추가하면 에이전트가 쓸 수 있는 기능도 하나 늘어납니다.

MCP

Hermes 설정의 mcp_servers에 등록하는 일반 MCP 서버입니다. 지금은 iris-control과 mobile-mcp를 쓰고, 다른 서버도 같은 방법으로 붙일 수 있습니다.

Models

Ollama 모델만 바꾸면 로컬 모델과 클라우드 모델, 작은 모델과 큰 모델을 바꿔 쓸 수 있습니다.

IDE

Eclipse Theia 기반 IRIS IDE와 Companion 패널이 들어 있습니다. Open VSX 확장도 설치할 수 있습니다.

Runtimes

음성 대화, 화면 학습, Android 에뮬레이터(전화 수신 감지·응답 포함)는 필요할 때만 따로 설치합니다.

Open source

GPL-3.0-or-later로 공개했습니다. 포크해서 스킬이나 MCP 연동을 추가할 수 있습니다.

GPLv3로 정한 이유

UI를 PyQt6로 만들었는데, PyQt6는 상업 라이선스를 사지 않으면 GPL-3.0-only입니다. 저장소에서 PyQt6가 들어간 dist/IRIS.exe를 직접 배포하기 때문에 이 조건을 따라야 합니다.

그래서 MIT나 Apache-2.0은 쓸 수 없었고 GPL-3.0-or-later로 정했습니다. 서드파티 라이선스 목록은 저장소 LICENSE.md에 있습니다.
