01해결하려는 문제

AI가 가장 필요한 사람이
AI를 가장 못 쓰고 있다.

학생, 취업 준비생, 이제 막 코딩을 배우는 사람. 이들이 AI 에이전트 앞에서 제일 먼저 마주치는 건 결제 화면과 긴 설치 문서다.

!비용쓸 만한 에이전트는 거의 다 월 구독이다. 배우는 동안, 사이드 프로젝트 하는 동안 매달 고정비를 내기는 어렵다.
!설치설치에서 이미 막힌다. 모델 런타임, 에이전트 게이트웨이, 도구를 따로 깔고 포트까지 맞춰야 한다. 터미널이 낯설면 첫 화면도 못 본다.
!간격답을 알려 주는 AI와 일을 해 주는 AI는 다르다. 모델을 돌리는 것과, 내 PC에서 파일을 고치고 명령을 실행하는 것 사이는 아직 멀다.

대상 사용자  학생 · 취업 준비생 · 초보 개발자 · AI 구독이 부담스러운 누구나

02IRIS가 하는 일

설치는 IRIS가,
실행은 에이전트가.

IRIS는 Ollama(모델)와 Hermes Agent(도구)를 PC에 알아서 깔고 이어 붙인 다음, 대화창 하나로 묶어 주는 오픈소스 데스크톱 앱이다.

01

원클릭 준비

setup.bat 더블클릭 한 번. 파이썬 가상환경부터 Ollama, 모델, Hermes 연결까지 시작 프로토콜이 끝낸다.

02

말하면 실행

자연어 한 줄로 파일을 고치고, 터미널을 돌리고, 웹을 찾는다. 진행 과정은 HUD에 실시간으로 흐른다.

03

먼저 알아챔

지켜보라고 고정해 둔 창이 멈추거나 승인을 기다리면, 사용자가 보기 전에 IRIS가 먼저 말을 건다.

Live Activity / Internal Log

모니터 감지 → 대화 → 도구 실행으로 이어지는 세션을 재구성한 예시

03AI 활용 방식

대답하는 AI를
일하는 AI로.

웹 검색, 셸, 파일 입출력은 IRIS가 새로 만들지 않았다. IRIS는 세션·권한·스트리밍 UI·시작 프로토콜을 맡고, 추론과 실행은 검증된 오픈소스에 넘긴다.

A
추론

Ollama 모델

Hermes Agent

tool-calling으로 파일을 읽고 고치고, 터미널 명령을 돌리고, 웹을 찾는다. 생각하는 과정과 도구 로그가 HUD에 그대로 뜬다.

C
감시

멀티모달 모델

D
자기 조작

08확장성

기능은
꽂아서 늘린다.

IRIS 본체는 얇게 두고, 할 줄 아는 일은 Hermes 스킬과 MCP 서버로 붙인다. 새 기능을 넣으려고 IRIS 코드를 고칠 필요가 없다.

Skills

기동할 때 스킬 10개를 Hermes에 자동으로 맞춘다. 스킬 폴더 하나를 더하면 에이전트가 할 줄 아는 일이 하나 는다.

MCP

Hermes 설정의 mcp_servers에 들어가는 표준 MCP 서버. 지금은 iris-control과 mobile-mcp, 다른 서버도 같은 방식으로 붙는다.

Models

Ollama 모델만 바꾸면 로컬과 클라우드, 경량과 대형을 오간다. 사양이 낮으면 클라우드로, 민감한 작업은 로컬로.

IDE

Eclipse Theia 기반 IRIS IDE와 Companion 패널을 내장했다. Open VSX 확장을 그대로 깔아 쓴다.

Runtimes

음성 대화, 화면 학습, Android 에뮬레이터(전화 수신 감지·응답 포함)는 필요할 때만 설치한다.

Open source

GPL-3.0-or-later로 전부 공개한다. 누구나 포크하고 스킬과 MCP 연동을 보탤 수 있다.

왜 GPLv3인가

UI 전체가 PyQt6 위에 있고, PyQt6는 상업 라이선스를 사지 않는 한 GPL-3.0-only다. 저장소가 PyQt6를 번들한 dist/IRIS.exe를 직접 배포하니 이 조건이 실제로 걸린다.

그래서 MIT·Apache-2.0은 고를 수 없었고, 그중 가장 열린 GPL-3.0-or-later로 정했다. 서드파티 목록은 저장소 LICENSE.md에 있다.

10기대 효과

AI를 쓰는 경험의 격차를
조금이라도 줄이는 쪽으로.

접근성

구독료와 에이전트 셋업이 부담인 학생·취준생·초보 개발자의 문턱을 낮춘다.

실습형 AI

답을 받아 보는 데서 끝나지 않고, 코딩·문서·파일 작업을 내 PC에서 직접 시켜 보며 익힌다.

격차 완화

PC 사양에 맞는 모델을 붙여, 돈과 장비 차이에서 오는 AI 경험의 차이를 줄인다.

프라이버시

설정·프로필·노트는 로컬에 둔다. 특정 네트워크나 벤더 하나에 묶이지 않는다.
