AI 에이전트.

IRIS는 Ollama와 Hermes Agent를 자동으로 준비하고 하나의 대화형 HUD로 묶는 데스크톱 앱입니다. 자연어로 요청하면 파일·터미널·웹 도구 실행까지 실시간 스트리밍으로 보여 줍니다.

문제 정의

AI를 가장 필요로 하는 사람이
가장 못 쓰고 있습니다.

학생·취준생·초보 개발자에게 최신 AI 에이전트는 두 겹의 벽입니다. 매달 나가는 구독비, 그리고 모델·게이트웨이·도구를 직접 엮어야 하는 설치 복잡도.

01 · 비용

구독이 전제가 된 도구들

쓸 만한 에이전트는 대부분 월 구독형입니다. 학습·사이드 프로젝트 단계에서 매달 고정비를 감당하기 어렵습니다.

02 · 진입 장벽

설치에서 이미 끝난다

모델 런타임, 에이전트 게이트웨이, 도구 연동을 각각 설치하고 포트를 맞춰야 합니다. 터미널이 낯설면 첫 화면조차 못 봅니다.

03 · 간격

"답만 주는 AI"와 실제 작업 사이

모델을 돌리는 것과, 내 PC에서 파일을 고치고 명령을 실행하는 에이전트 사이에는 여전히 큰 간격이 있습니다.

동작 구조

직접 만들지 않고, 제대로 엮습니다.

IRIS는 웹검색·셸·파일 IO를 자체 재구현하지 않습니다. 세션·권한·스트리밍 UI·시작 프로토콜을 담당하고, 실제 실행은 Ollama와 Hermes에 위임합니다. 검증된 오픈소스 위에 사용성을 얹는 구조입니다.

주요 기능

하나의 HUD 안에서 끝납니다.

시작 프로토콜

첫 실행 시 Ollama·최소 모델·Hermes 설치와 provider·gateway·MCP 연동을 단계적으로 안내하고 자동화합니다.

대화형 HUD

모델 선택, 대화 이력, 사고·도구 로그를 한 화면에서 실시간 스트리밍으로 확인합니다.

에이전트 실행

Hermes를 통해 파일·터미널·웹 도구를 호출합니다. 스킬과 MCP 확장을 포함합니다.

시스템 모니터

창·리소스를 인식하고 알림 정책에 따라 Live Activity로 상태 변화를 전달합니다.

이메일

다중 계정 메일 워크스페이스를 HUD 안에서 직접 다룹니다.

Iris Wiki

Obsidian 호환 vault 기반 프로젝트 문서와 ~/.iris-light/iris-wiki 사용자 노트.

캘린더

일정 워크스페이스를 에이전트와 연동해 자연어로 다룹니다.

로컬 저장

설정·프로필·계정 정보는 외부 서버가 아닌 로컬 SQLite에 보관합니다.

선택 확장

음성 런타임(알림 낭독), 화면 학습(Aloha), Android 에뮬레이터·mobile-mcp 연동을 필요할 때만 설치합니다.

첫 실행 순서

사용자가 외워야 할 명령어는 없습니다.

아래는 IRIS가 사용자를 대신해 순서대로 처리하는 실제 단계입니다. 각 단계는 실패하면 원인과 해결 명령을 화면에 안내합니다.

STEP 1
Python 환경 확인
py -3.13/-3.12/-3.11 순으로 탐색하고, 없으면 설치 링크와 winget 명령을 안내합니다.
STEP 2
가상환경 · 패키지 설치
.venv 생성 후 requirements.txt 전체 설치. 프록시·사내망 환경용 대체 명령까지 제공합니다.
STEP 3
핵심 패키지 import 검증
PyQt6 등을 실제로 import 해 확인하고, 실패 시 VC++ 재배포 패키지 설치 명령을 띄웁니다.
STEP 4
Ollama 설치 · 기동 · 모델 pull
공식 설치 경로를 따라 런타임을 준비하고 최소 모델을 내려받습니다.
STEP 5
Hermes 설치 · provider 연결
에이전트 게이트웨이를 설치하고 API·provider를 연결한 뒤 gateway를 기동합니다.
STEP 6
선택 항목은 나중에
음성 STT/TTS, 화면 학습, 에뮬레이터, mobile-mcp는 「설치」 또는 「나중에」를 고를 수 있습니다.

3분 만에 시작하기

파이썬을 처음 써 보는 분도 명령어 입력 없이 설치할 수 있습니다.

01
저장소를 내려받습니다
GitHub에서 Code → Download ZIP 후 압축을 풉니다.
02
setup.bat 더블클릭
파이썬 확인 · 가상환경 · 패키지 설치 · 검증까지 전부 자동입니다.
03
run.bat 더블클릭
시작 위저드가 Ollama · Hermes 설치를 이어서 안내합니다.
저장소 열기
터미널을 쓰고 싶다면 — PowerShell
# 기본 설치
.\setup.ps1

# 설치 후 바로 실행
.\setup.ps1 -Run

# 선택 음성 런타임까지
.\setup.ps1 -Voice

# 설치가 꼬였을 때 재생성
.\setup.ps1 -Recreate

# 실행
.\run.bat

라이선스 근거

IRIS의 UI는 전부 PyQt6 위에 올라가 있고, PyQt6는 상업 라이선스를 사지 않는 한 GPL-3.0-only입니다. 저장소가 PyQt6를 번들한 dist/IRIS.exe를 직접 배포하므로 이 조건이 실제로 적용됩니다.

따라서 MIT·Apache-2.0은 선택할 수 없으며, 제약을 만족하는 것 중 가장 개방적인 선택이 GPL-3.0-or-later입니다. 서드파티 라이선스 인벤토리와 모델 가중치·음성 데이터 취급 기준은 저장소 LICENSE.md에 정리돼 있습니다.

기대 효과

AI 경험의 격차를 줄이는 쪽으로.

접근성

구독료와 에이전트 셋업 부담이 큰 학생·취준생·초보 개발자의 진입 장벽을 낮춥니다.

실습형 AI

답만 받는 소비를 넘어, 코딩·문서·파일 작업을 내 PC에서 직접 수행하며 활용 역량을 키웁니다.

격차 완화

PC 사양에 맞는 모델을 연결해, 경제적·디지털 격차로 인한 AI 경험 불평등을 줄이는 데 기여합니다.

프라이버시

설정·프로필·노트를 로컬에 두고, 네트워크나 특정 벤더에만 의존하지 않는 사용이 가능합니다.
